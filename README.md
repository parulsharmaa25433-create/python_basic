# Python Basic

A simple Python project containing a basic factorial program.

## Project Description

This project contains a Python program that calculates the factorial of a fixed number.

## Features

- Calculates the factorial of a number
- Uses a `for` loop for calculation
- Simple and beginner-friendly Python program

## Requirements

- Python 3.x

No external libraries are required.

## Installation

1. Clone this repository.
2. Make sure Python 3.x is installed.
3. No additional dependencies are required.

## Usage

Run the program using:

```bash
python factorial.py
## Example

For n = 5, the output is:

120

## How It Works

The program uses a for loop to multiply numbers from 1 to 5 and calculates the factorial.
